# Portfolio

A simple HTML/CSS portfolio website similar to Emily Douglas's Wix site.

## Viewing the Site

To view the site locally:

1. Ensure you have Python installed.
2. Run `python3 -m http.server 8000` in the project directory.
3. Open http://localhost:8000 in your browser.

## Files

- `index.html`: Homepage with projects
- `about.html`: About page
- `contact.html`: Contact page
- `styles.css`: Stylesheet

## Deployment

Upload these files to any static web hosting service like GitHub Pages, Netlify, or Vercel.
